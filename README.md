# 摸鱼时钟

一个简洁美观的番茄钟网页应用，帮助你高效管理工作与休息时间，提升专注力。

## 项目简介
摸鱼时钟基于番茄工作法设计，支持工作与休息倒计时，界面清新，适合日常学习和办公使用。

## 主要功能
- 25分钟工作计时
- 5分钟休息计时
- 一键开始、暂停、重置
- 动态水波纹与气泡动画背景
- 响应式设计，适配移动端

## 使用方法
1. 打开 `index.html` 文件即可在浏览器中使用。
2. 点击“开始”按钮启动计时。
3. 可随时暂停或重置计时。

## 技术栈
- HTML5
- CSS3（含动画效果）
- 原生 JavaScript

## 启动方式
无需安装依赖，直接用浏览器打开项目根目录下的 `index.html` 文件即可。
