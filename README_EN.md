# Fish-Petting Clock

A simple and beautiful Pomodoro timer web app to help you efficiently manage work and break times, boosting your focus.

## Project Overview
Fish-Petting Clock is designed based on the Pomodoro Technique. It supports work and break countdowns with a clean interface, suitable for daily study and office use.

## Main Features
- 25-minute work timer
- 5-minute break timer
- One-click start, pause, and reset
- Dynamic water ripple and bubble animation background
- Responsive design for mobile devices

## Usage
1. Open the `index.html` file in your browser.
2. Click the "Start" button to begin timing.
3. You can pause or reset the timer at any time.

## Tech Stack
- HTML5
- CSS3 (including animation effects)
- Vanilla JavaScript

## How to Start
No dependencies required. Simply open the `index.html` file in the project root directory with your browser.
